# topographic-hierarchy

Do brain regions that sit farther from primary sensory cortex match deeper layers of a model? This repo tests that across recording datasets and models. Each dataset provides a signal per electrode or sensor and a position along a topographic axis (distance from primary auditory cortex, A1). Each model provides activations for every layer. For each unit, a lagged ridge regression predicts the signal from each layer, and the layer with the highest held-out correlation is that unit's best layer. The topographic result is the rank correlation between axis position and best layer, with subject-level statistics and controls.

## Results so far

Podcast ECoG (OpenNeuro ds005574), stGRU (frozen SpikeSpeechBrain trained on LibriSpeech), 15 layers, `mems` array. Significant electrodes only (shuffled-time null, p < 0.01).

| Dataset | Model | Band | Spearman rho (95% subject-bootstrap CI) | n electrodes | within-subject permutation p | slope (layers per 10 mm) |
|---|---|---|---|---|---|---|
| Podcast ECoG | stGRU | high gamma 90-150 Hz | 0.57 (0.43 to 0.70) | 199 | < 0.0001 | 1.34 (0.92 to 1.58) |
| Podcast ECoG | stGRU | mid gamma 60-90 Hz | 0.48 (0.36 to 0.56) | 260 | < 0.0001 | 1.17 (0.79 to 1.44) |
| Podcast ECoG | stGRU | low gamma 30-60 Hz | 0.43 (0.32 to 0.52) | 191 | < 0.0001 | 1.09 (0.73 to 1.32) |
| Podcast ECoG | stGRU, audio envelope regressed out | high gamma | 0.58 (0.43 to 0.69) | 156 | | |

- High gamma has a higher rho than mid gamma (difference 0.10, CI 0.03 to 0.18) and than low gamma (0.14, CI 0.05 to 0.24). Mid and low gamma are not separable (0.04, CI -0.05 to 0.15).
- Audio-envelope dry run (distance from A1 against envelope tracking, high gamma 90-150 Hz, preprocessed signal): rho = -0.327 (n = 1,268).
- Full details: `reports/weekly_report_10_13_20.pdf`.

Planned rows: random-initialized stGRU, stGRU with feedback removed, other speech models, other datasets (MEG-MASC), and a second spatial axis beyond distance from A1.

## Data: what, where, how

Data are not stored in this repo. The ECoG recordings and stimulus are public. The model activations are a derived file from the model authors. Full steps are in `docs/data_download.md`; the summary is below.

| Input | Where to get it | Put it in |
|---|---|---|
| Podcast ECoG, preprocessed (`ecogprep` derivative `.fif`) | OpenNeuro ds005574 v1.0.2, https://openneuro.org/datasets/ds005574 (DataLad or `openneuro-py`) | `data/ds005574/derivatives/ecogprep/` |
| Podcast audio (`podcast.wav`) | same dataset (stimuli) | `data/podcast/podcast.wav` |
| Electrode table with distance to A1, parcel, stage | in this repo: `electrodes_good_labeled.csv` | repo root |
| stGRU activations `fbanks_v295_podacast.h5` (4.1 GB) | not public; request from the model authors (Archimedes AI / Costas group) | `data/models/` |

Download the dataset with DataLad:
```
datalad install https://github.com/OpenNeuroDatasets/ds005574.git data/ds005574
cd data/ds005574 && datalad get derivatives/ecogprep sub-*/ieeg stimuli
```

Use the `ecogprep` derivative, not the raw EDF files. The raw files lack the notch filter, common average reference and spike removal, and bands built from them changed the envelope dry-run correlation from -0.327 to -0.205.

Everything downstream is generated by the commands below: filtered bands, stitched activations, run folders. The small result files that support the numbers above (per-electrode best layers, summaries, permutation and slope tables, area tables, run settings) are committed in `results/`, so the statistics and figures can be checked without the raw data.

## Layout

```
src/
  datasets/<dataset>/     loaders: raw data -> signal on the 80 ms clock + electrode table
  models/<model>/         activation extraction and stitching onto the 80 ms clock
  topography/             shared analysis (does not depend on dataset or model)
  controls/               audio-envelope dry run and other controls
results/<dataset>/<model>/<run_name>/   small CSVs, run_info.json and run figures for each run
results/<dataset>/controls/             model-independent controls (envelope dry run)
figures/<dataset>/<model>/              curated figures per model
figures/<dataset>/controls/             model-independent figures
figures/<dataset>/compare/               cross-model comparison figures
reports/                  weekly reports (LaTeX and PDF)
docs/                     data download instructions
electrodes_good_labeled.csv
```

## Reproducing the podcast ECoG x stGRU result

Run from the project root, with data in `data/` as above.

```
# 1. Filter five bands from the preprocessed ecogprep signal
python src/datasets/podcast_ecog/export_bands_ecogprep.py \
  --root data/ds005574/derivatives/ecogprep --electrodes electrodes_good_labeled.csv

# 2. Put the model activations on the 80 ms clock (one file per layer)
python src/models/stgru/stitch_layers.py data/models/fbanks_v295_podacast.h5 data/stitched

# 3. Audio-envelope dry run
python src/controls/envelope_dry_run.py --fif_root data/ds005574/derivatives/ecogprep \
  --electrodes electrodes_good_labeled.csv --wav data/podcast/podcast.wav

# 4. Gate 1, main run (low, mid and high gamma, all 15 layers)
python src/topography/gate1_tier1.py --stitched data/stitched \
  --ecog data/pavlos_handoff/ecog_bands_ecogprep.h5 --electrodes electrodes_good_labeled.csv \
  --model_name stgru --dataset podcast_ecog \
  --bands low_gamma mid_gamma high_gamma --out_root results/podcast_ecog/stgru

# 5. Acoustic control: same run with the lagged audio envelope regressed out
python src/topography/gate1_tier1.py <same arguments> --bands high_gamma \
  --regress_envelope --wav data/podcast/podcast.wav

# 6. Statistics and breakdowns on a finished run folder
python src/topography/gate1_permutation.py --run <run folder>
python src/topography/gate1_slope.py --run <run folder>
python src/topography/gate1_areas.py --run <run folder> --electrodes electrodes_good_labeled.csv
```

Main run settings: ridge alpha grid 1e3 to 1e7 chosen per layer, 64 PCs per layer, 8 lags (0 to 560 ms), 5 contiguous CV folds with a 25-frame buffer, 20 shuffled-time null repeats (offset of at least 60 s), significance at p < 0.01, 2,000 bootstrap resamples (10,000 for slope and band comparisons), seed 0. All settings are saved in `run_info.json` in each run folder.

## Adding a dataset or model

- A dataset loader must produce signal arrays on the 80 ms clock per subject and an electrode table with subject, name, a topographic axis value (currently `dist_to_A1_mm`), and anatomical labels.
- A model adapter must produce one `<array>_layer<N>.npz` per layer on the same clock (see `src/models/stgru/stitch_layers.py`).
- Run `gate1_tier1.py` with `--model_name` and `--dataset`. Results and figures go in `results/<dataset>/<model>/` and `figures/<dataset>/<model>/`. The statistics scripts work on any run folder.

## Known limits

- The stGRU activations come from a placeholder inference run (30 s windows, 4 s padding). Results are provisional until the final run.
- Only the `mems` array has been analyzed.
- The ridge penalty is chosen on the same folds used for scoring.
- The subject bootstrap and permutation tests do not include the significance filter or the layer selection. A full-pipeline shift test is not yet run.
- The audio-envelope control removes broadband loudness only.
